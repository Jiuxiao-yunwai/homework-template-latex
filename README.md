# 中文 LaTeX 作业模板

本模板专为理工类作业、编程实验报告及日常习题解答设计，原生支持完美的中文排版。

## ✨ 核心特性

* **双模式题目渲染** ：提供了一个全局编译开关。开启时完整显示“题目+解答”；关闭时自动隐藏题目描述，仅导出“纯净答案版”。
* **智能的目录结构** ：通过 `\begin{problem}` 环境，自动按章节递增生成题号（如 1.1），并将其作为二级标题自动加入到 PDF 目录与侧边书签中。
* **自定义编号支持** ：支持使用 `\begin{problem}[自定义题号]` 插入额外题目而不打乱原有的自动计数逻辑。
* **跨页解答保护** ：基于 **tcolorbox** 深度定制了 `answer` 答案框。当解答步骤或公式过长需要换页时，页面底端和下一页顶端都会自动补充闭合边框。
* **优雅的代码环境** ：将 `lstlisting` 封装为极致精简的 `\begin{code}[language]` 环境。底层搭载了还原度极高的 **GitHub** 代码高亮配色，并全局强制启用等宽字体排版。
* **安全的图文混排** ：内置了在具有物理边界的解答框中，安全插入图片并自动生成标准图注的排版方案。

## 🛠️ 环境依赖与编译

* **编译引擎** ：请务必使用 **XeLaTeX** 引擎进行编译，以保证中文与特殊字体的正常渲染。文档头部已预置魔法注释 `% !TEX program = xelatex` 。
* **文本编码** ：要求使用 **UTF-8** 编码。
* **必备字体** ：为了呈现最完美的英文字符与代码对齐效果，代码块默认指定调用系统中的 **Maple Mono** 字体。若本地未安装，可通过修改 `\setmonofont` 参数切换为其他等宽字体。

## 🚀 快速起步

### 1. 编写题目
使用 `problem` 环境来生成题目。

```latex
\section{第一章}

% 自动生成“题目 1.1”
\begin{problem}
请写出牛顿第二定律的公式。
\end{problem}

% 自定义编号为 9.9
\begin{problem}[9.9]
请插入一段 Python 代码。
\end{problem}
```

### 2. 编写解答与代码
紧跟在题目后使用 `answer` 环境。插入代码时，使用我们封装好的 `code` 环境。

```latex
\begin{answer}
这里是解答区域，支持直接插入跨页长公式：
\[ F = ma \]

\begin{code}[Python]
def hello_latex():
    print("代码环境完美运行！")
\end{code}
\end{answer}
```

### 3. 一键切换显隐模式
在 `.tex` 源码的最上方导言区，找到这行代码：
```latex
\showproblemtrue  % 模式 1：显示完整题目内容
```
如果想只导出答案，将其注释并替换为 `\showproblemfalse` 即可瞬间隐藏所有题目正文。
